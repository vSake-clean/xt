# Key Copier (Android)

Odczyt kodu klucza z ekranu telefonu (działanie jak Key Copier na Flipper Zero).

1. Kalibracja ekranu kartą płatniczą (85,60 × 53,98 mm).
2. Wybór profilu: Europrofil 5/6 pin (ogólny), Kwikset KW1/KW10, Schlage SC1/SC4, Yale Y1, Master M1 lub własny.
3. Klucz na ekranie, ramię przy czerwonej linii, ustawianie głębokości każdego nacięcia (▲▼ / przeciąganie).
4. Zapis kodu.

Build: `./gradlew assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`
